在 Safari 开始使用

  1. 1

    启用 Userscripts

    从 App Store 安装 Userscripts ↗，打开一次。到 iPhone「设置 → App → Safari → 扩展」启用它。旧版 iOS 的入口在「设置 → Safari」。

  2. 2

    安装这份脚本

    点上方「安装本地脚本」，再打开 Safari 的扩展菜单，选择 Userscripts 并确认安装。脚本文件也可以保存到 Userscripts 的脚本目录。

    bili-local.user.js 2.2.0 · JS 和样式已打包
  3. 3

    打开 B 站，允许脚本运行

    访问 bilibili.com，在 Safari 扩展菜单允许 Userscripts 访问 B 站。需要登录时使用 B 站官方登录；登录状态由 Safari 保留。

✓

账号始终由 B 站管理

不读取、导入或上传账号 Cookie。所有 B 站请求从你的设备发出，Cloudflare 只分发静态文件。推荐缓存、浏览记录和稍后再看留在本机。

脚本只在 www.bilibili.com 和 m.bilibili.com 的首页、视频页运行。用户脚本能修改页面，请仅安装你信任的代码。无需给予所有网站权限。

为什么不能直接在这个网页刷视频？

普通独立网页受浏览器跨域和 Cookie 隔离限制，无法直接沿用 B 站登录。用户脚本让界面运行在 B 站页面中，浏览器才可以直接使用官方登录状态。纯前端分发可避免 Cloudflare 出口 IP 限制，本地网络或账号仍可能受 B 站风控影响。

如何恢复官方界面？

点「我的 → 返回官方界面」，或在 Userscripts 中停用此脚本。脚本不改变 B 站账号设置，不自动点赞或关注。
